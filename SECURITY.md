# Reporting a vulnerability

Please report suspected security vulnerabilities privately through [GitHub's Report a vulnerability form](https://github.com/Brian-An/turnstone/security/advisories/new).
Include the affected version, reproduction steps, and a minimal disposable sample when possible.
Do not post private documents, credentials, or exploit details in public issues.

Turnstone is preview software.
Security fixes target the current source and latest preview; older previews do not receive separate fixes.
Use ordinary [issues](https://github.com/Brian-An/turnstone/issues/new/choose) for conversion errors, feature requests, and setup questions that do not involve a vulnerability.
